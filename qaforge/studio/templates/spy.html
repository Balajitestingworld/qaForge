Capture locators

Studio signs in through Okta, opens the screen and lists its elements. Each locator is built the way Playwright recommends (test id, role and name, label…) and then run against the live page. It is kept only if it finds exactly that one element.

Good to know

  • Screens deep inside a journey (for example a confirmation page) are easiest with “Pick elements”, or record the journey and save its locators.
  • Values shown on screen that look like account numbers, card numbers or balances are never used inside a locator, and are blacked out in the screenshot.
  • Ask developers to add data-testid to buttons and fields; those locators survive redesigns best.
